# Wazap setup for AI agents

The setup guide is [USE-ME.md](USE-ME.md). Read it before configuring Wazap. It covers existing installations, account selection, local and remote clients, phone pairing, first-read verification and recovery.

If your harness cannot open that file, run `npx -y wazap-mcp@0.15.0-beta.1 setup --agent`. The command prints the entire guide on stdout without starting setup. Use the inspected installation's `wazap setup --agent` instead when one already exists.
